# NEW TOEFL 리딩 모의고사

학생이 로그인 없이 브라우저에서 푸는 리딩 모의고사. 문제와 정답은 이 저장소가 아니라 선생님의 구글 시트에 있고, 채점도 구글 쪽에서 한다.

- `index.html` — 학생 페이지 (이름 + 입장 코드로 입장)
- `admin.html` — 관리자 페이지 (입장 코드, 열린 회차, 결과 보기, 회차 올리기)
- `config.js` — Apps Script 웹 앱 주소
- `apps-script/Code.gs` — 구글 시트에 붙여 넣는 서버 코드

문제 파일(`tests.json`)은 저장소에 올리지 않는다. 관리자 페이지의 "문제" 탭에서 올린다.
